디자인 시안 (3벌)

홈 · 식단상세 화면의 시각적 방향 비교. 각 카드의 "컨셉 문서"에 원칙과 상태별 동작 규칙이 정리돼 있습니다.

CONCEPT 1
codex 1번 시안

오늘의 식사를 카드 우선순위로 안내하는 홈. 조식·중식·석식 고정 순서 안에서 현재/다음 식사만 확장 카드로 강조.

홈 화면 → 상세 화면 → 컨셉 문서
CONCEPT 2
codex 2번 시안

시간 흐름을 한눈에 보여주는 식단 보드. 날짜 이동 + 세로 타임라인으로 진행 위치를 명확히 전달.

홈 화면 → 상세 화면 → 컨셉 문서
CONCEPT 3
claude 시안

사진 중심의 오늘의 한 끼 안내. 현재/다음 식사를 큰 이미지 위 매거진형 히어로 카드로 강조.

홈 화면 → 상세 화면 → 컨셉 문서

퍼블리싱 구조

디자인이 아니라 코드 구조(파일 구성·리소스 관리 방식) 검증용. 개발팀 리뷰가 진행 중입니다.

STRUCTURE
퍼블리싱 구조 초안
