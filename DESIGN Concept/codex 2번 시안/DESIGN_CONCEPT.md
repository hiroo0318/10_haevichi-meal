# Codex 2번 시안 디자인 컨셉

## 한 줄 방향

**시간 흐름을 한눈에 보여 주는 식단 보드**. 날짜 선택과 세로 타임라인을 통해 오늘 식사의 진행 위치를 명확히 전달한다.

## 유지할 핵심 원칙

- 홈 상단에서 날짜를 직접 이동할 수 있으며, 선택한 날짜가 오늘이 아닐 때만 `오늘로` 복귀 버튼을 보여 준다.
- 식사의 시간 순서와 진행 상태는 세로 타임라인으로 표현한다. 조식 → 중식 → 석식의 시간 흐름이 화면 구조 자체가 된다.
- 보드 헤딩은 현재 맥락을 한 문장으로 요약한다. 예: `지금 제공 중인 식사`, `석식을 준비하고 있어요`.
- 해당 시간대의 식사만 타임라인 안에서 확장한다. 확장 항목에는 메뉴 구성, 식사 사진, 상세 보기, 상태 뱃지를 표시한다.
- 과거 식사는 읽기 전용의 간결한 행으로, 다음 식사는 시작 시각 중심으로, 제공 중 식사는 강한 강조로 구분한다.

## 화면 구성 규칙

1. 상단: 현대캐피탈 급식 브랜드, 사업장 선택
2. 날짜 패널: 이전/다음 날짜, 선택 날짜, 조건부 오늘 복귀
3. 공지
4. 식사 보드 헤딩: 현재/다음 상태와 시간 요약
5. 세로 타임라인: 조식·중식·석식
6. 석식 후 종료 안내
7. 급식 안내 카드와 하단 탭

## 상태별 동작

- 조식 전 / 조식 중: 조식 타임라인 항목을 확장한다.
- 조식 완료 + 중식 전 / 중식 중: 중식 타임라인 항목을 확장한다.
- 중식 완료 + 석식 전 / 석식 중: 석식 타임라인 항목을 확장한다.
- 석식 후: 확장 항목 없이 종료 안내를 표시한다.
- 검토 시 `board-heading`의 `data-preview-state` 속성 또는 상단 상태 미리보기로 모든 상태를 즉시 확인할 수 있다. 운영에서는 `auto` 또는 속성 제거 후 운영시간을 기준으로 계산한다.

## 상세 화면 확장 기준

- 넓은 메뉴 사진과 짧은 상태 캡션으로 시작한다.
- 식단 구성은 항목별 정의 목록으로, 영양·알레르기는 요약 블록으로 보여 준다.
- 원산지는 태그로 간결하게 표시한다.
- 메뉴 평가는 평가 전/평가 후 두 상태가 존재하되, 실제 화면에는 사용자의 평가 여부에 맞는 한 상태만 노출한다. 현재 병렬 표기는 시안 검토용이다.

## 표현 자산 및 주의사항

- 현대캐피탈 블루와 짙은 네이비 하단 탭을 기본 축으로 사용한다.
- 타임라인의 선·점·시간은 장식이 아니라 식사 진행 순서를 읽게 하는 핵심 정보다.
- 모든 샘플 음식 사진은 로컬 `images` 폴더를 참조한다.
- 상태 미리보기는 검토용 도구이므로 실제 퍼블리싱 시 노출 정책을 별도로 결정한다.
