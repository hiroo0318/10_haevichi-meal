# Codex 1번 시안 디자인 컨셉

## 한 줄 방향

**오늘의 식사를 카드 우선순위로 안내하는 홈**. 조식·중식·석식의 고정 순서 안에서 현재 또는 다음 식사만 확장 카드로 강조한다.

## 유지할 핵심 원칙

- 상단 인트로는 날짜와 “오늘, 어떤 식사가 기다리고 있을까요?”라는 환영 메시지로 시작한다.
- 식사 순서는 언제나 **조식 → 중식 → 석식**이다. 시간대에 따라 순서를 바꾸지 않는다.
- 강조 대상 한 건만 메뉴 구성·상세 보기·사진·원산지/알레르기를 포함한 확장 카드로 표시한다.
- 이미 종료된 식사는 썸네일과 상세 보기 문구 없이 간결한 목록으로 표시한다. 단, 카드 자체의 상세 이동 가능성은 유지한다.
- 이미지와 텍스트는 강조 카드의 두 행 구조를 따른다.
  - 상단 행: 식사 구분·시간·메뉴명·상태
  - 하단 행: 메뉴 구성/상세 보기와 식사 썸네일

## 상태 표현 규칙

| 상태 | 강조 카드 | 우측 상태 |
| --- | --- | --- |
| 다음 식사 | 밝은 블루 바탕, 파란 테두리·텍스트 | `다음 식사` |
| 제공 중 | 진한 현대캐피탈 블루 바탕 | 초록 라이브 점 + `제공 중` |
| 종료된 식사 | 일반 목록 행 | 상태 뱃지 없음 |
| 석식 후 | 강조 카드 없음, 종료 안내 카드 | `오늘의 식사가 종료되었습니다` |

조식도 다른 끼니와 동일하게 우측 상태 뱃지를 사용한다. 평점은 조식이 강조될 경우 메뉴명 아래의 보조 정보(`★ 4.0 · 평가 완료`)로 표시한다.

## 상태별 강조 대상

- 조식 전 / 조식 중: 조식 확장 카드
- 조식 완료 + 중식 전 / 중식 중: 중식 확장 카드
- 중식 완료 + 석식 전 / 석식 중: 석식 확장 카드
- 석식 후: 확장 카드 없음 + 종료 메시지

## 상세 화면 확장 기준

- 홈의 강조 카드와 동일한 메뉴 사진, 식사명, 시간, 상태를 상세 첫 화면에서도 연속성 있게 사용한다.
- 상세 정보는 식단 구성 → 영양/알레르기 → 원산지 → 메뉴 평가 순으로 배치한다.
- 메뉴 평가는 사용자 상태에 따라 평가 전 또는 평가 후만 실제 화면에 표시한다. 두 상태 동시 표기는 시안 검토 목적이다.

## 구현·운영 메모

- `home-concept.js`의 상태 스위처는 검토용이며, 실제 구현에서는 사업장별 운영시간과 식단 API 데이터로 같은 클래스를 계산한다.
- 고객사별 색상 변경이 가능하도록 현대캐피탈 블루는 테마 값으로 관리한다.
- 식사 사진은 로컬 `images` 폴더의 실제 식사형 샘플을 사용하며, 운영에서는 메뉴 이미지 데이터로 대체한다.
