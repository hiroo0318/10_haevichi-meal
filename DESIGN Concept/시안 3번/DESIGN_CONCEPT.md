# 시안 3번 디자인 컨셉

## 한 줄 방향

**사진 중심의 오늘의 한 끼 안내**. 사용자가 앱을 열자마자 현재 또는 다음 식사를 큰 이미지와 짧은 안내 문구로 확인하게 한다.

## 유지할 핵심 원칙

- 상단은 현대캐피탈 급식 브랜드와 사업장 선택만 남겨 단정하게 시작한다.
- 홈의 주인공은 `spotlight` 카드다. 현재 제공 중이거나 다음 식사를 사진·메뉴명·운영시간·핵심 태그로 크게 보여 준다.
- 조식 → 중식 → 석식의 순서는 아래 타임라인에서 항상 유지한다. 강조 대상만 시간대에 따라 바뀐다.
- 식사 사진은 장식이 아니라 메뉴 식별 요소다. 실제 식단과 최대한 유사한 로컬 이미지를 사용한다.
- 상태는 `다음 식사`, `제공 중`, `오늘 식사 종료`를 짧고 직접적으로 표현한다. 제공 중일 때는 현시성을 더 강하게 준다.

## 화면 구성 규칙

1. 상단: 브랜드, 사업장 선택
2. 안내: 공지 한 줄
3. Spotlight: 현재/다음 식사 한 건의 대표 카드
4. 전체 식단: 조식·중식·석식 타임라인 목록
5. 종료 상태: 식사 종료 안내 카드
6. 하단 탭: 홈 · 식단 · 의견 · 공지 · MY

## 상태별 동작

- 조식 전/중식 전/석식 전: 해당 끼니를 `다음 식사`로 Spotlight에 표시한다.
- 조식 중/중식 중/석식 중: 해당 끼니를 `제공 중`으로 Spotlight에 표시한다.
- 석식 후: Spotlight 대신 종료 안내를 표시하고, 세 끼는 목록으로만 남긴다.
- 상단의 상태 미리보기는 시안 검토용이다. 실제 서비스에서는 사업장별 운영시간과 식단 데이터로 상태를 계산한다.

## 상세 화면 확장 기준

- 대표 사진을 넓게 사용하고, 식사 구분·시간·상태를 사진 위 또는 바로 아래에 연결한다.
- 식단 구성, 영양/알레르기, 원산지, 평가를 정보 덩어리별로 나눈다.
- 평가는 `평가 전`과 `평가 후`를 하나의 화면에서 동시에 노출하지 않고 실제 사용자 상태에 맞는 한 가지 상태만 보여 준다. 현재의 동시 표기는 검토용 샘플이다.

## 코너(끼니 내 복수 메뉴) 지원

같은 끼니(조식/중식/석식)에 코너 A, 코너 B처럼 서로 다른 메뉴가 동시에 제공될 수 있다는 요건이 추가되어 반영했다.

- **데이터 구조**: 끼니 → 코너 목록 → 코너별 메뉴(사진·구성·영양·알레르기·별점) 순으로 한 단계 깊어진다.
- **홈 스포트라이트(A안 채택)**: 코너가 2개 이상이면 대표 코너를 기본으로 보여주고, 시간 배지 옆에 코너 전환 탭(`코너 A` / `코너 B`)을 추가한다. 탭을 누르면 사진·메뉴명·설명·태그·CTA 링크가 전부 그 코너 기준으로 바뀐다. 코너가 1개인 끼니는 지금까지처럼 탭 없이 그대로 노출한다.
- **하루 식단 타임라인(B안 채택)**: 코너 개수와 무관하게 항상 "끼니 그룹 헤더(`중식 · 11:30–13:30 · 코너 2개`) + 코너별 줄" 구조로 통일한다. 코너가 1개뿐인 조식/석식도 헤더 아래 줄 하나로 표시하고, 줄에는 "코너 A(한식)"처럼 코드+타입을 항상 노출한다(코너가 1개여도 어떤 코너인지 구분 가능해야 하므로). 다만 헤더의 "코너 N개" 문구는 코너가 2개 이상일 때만 붙인다.
- **상세 화면**: 헤더 바로 아래에 코너 전환 탭을 두고(코너가 2개 이상일 때만 노출), 탭에 따라 사진부터 별점까지 화면 전체가 그 코너 기준으로 다시 그려진다. URL의 `?meal=lunch&corner=b`로 특정 코너에 바로 진입할 수 있다.
- **별점 정책**: 별점은 코너마다 독립적으로 등록한다(같은 끼니라도 실제로는 다른 메뉴를 먹었을 수 있으므로). 코너를 전환해도 이미 등록한 별점은 유지되고, 아직 평가하지 않은 코너는 별도로 평가해야 한다.

## 홈 화면 평가 상태 표시 (기획 변경 반영)

- **결정**: 홈 타임라인에서 `평가완료`/`평가 전` 같은 개인 평가 상태 뱃지를 제거했다. 대신 지나간 끼니에 평균 별점 데이터가 있으면 `★ 4.0`처럼 숫자만 보여주고, 없으면 아무 배지도 표시하지 않는다.
- **이유**: 실서비스 디자인 검토에서 "개인 평가 여부 노출은 기획 변경으로 제외"로 확정됨. `제공 중`/`곧 시작` 같은 운영 상태 배지는 개인 평가와 무관하므로 그대로 유지한다.
- **영향**: `cornerStateBadge()`가 과거 끼니에 대해 `rated` 여부에 따라 별점 숫자만 반환하거나 빈 문자열을 반환하도록 변경됨(`home-concept.js`).

## 타이포그래피 굵기 체계 (실서비스 검토 반영)

실서비스 디자인 검토에서 "굵은 텍스트가 여러 영역에 반복되어 위계가 약해진다"는 지적을 받아 굵기 체계를 3단계로 단순화했다.

- **Bold(700~800)**: 메뉴명, 화면/섹션 제목처럼 반드시 강조해야 하는 요소에만 사용한다.
- **Medium(600)**: 시간, 코너명, 상태 배지, 탭 라벨처럼 보조 정보에 사용한다.
- **Regular(400~500)**: 설명 문구, 태그 텍스트처럼 가장 낮은 우선순위 정보에 사용한다.
- 코너 전환 탭·"자세히" 링크의 터치 영역은 최소 36~40px 높이를 확보했다.
- 스포트라이트 사진 오버레이 농도를 낮추고, 타임라인 그룹 간 여백과 목록 하단-탭바 간 여백을 늘렸다.

## 표현 자산 및 주의사항

- 현대캐피탈 블루 계열과 밝은 중립 배경을 사용한다. 브랜드 색상은 고객사별 테마 토큰으로 교체 가능해야 한다.
- 사진·아이콘은 모두 해당 시안 폴더의 로컬 `images`를 참조한다.
- 실제 퍼블리싱 전에는 검토용 상태 스위처와 샘플 문구를 제거하거나 개발 전용 플래그로 분리한다.
